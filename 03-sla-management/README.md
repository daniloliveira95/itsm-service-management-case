# SLA Management

Documentation of Service Level Agreement (SLA) configuration and operational monitoring using Jira Service Management.

## Overview

This case documents the implementation of SLA policies designed to organize service desk response times, establish operational expectations and support ticket management.

## Scope

- First Response SLA
- Customer Response SLA
- Follow-up SLAs
- SLA configuration and monitoring
- Operational rules and conditions
- JQL queries and technical evidence
